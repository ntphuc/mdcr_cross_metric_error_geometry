# Released results

`mdcr_publication_suite_v3_final/` contains the outputs of the 8 architecture-seed runs reported in the paper
(EfficientNet-B0 U-Net seeds 42, 123, 2024, 2026, 3407; ResNet18 U-Net seeds 42, 123, 2024).

- `analysis/` - per-seed and multi-seed summaries (Tables 3-5, router, bottleneck decisions).
- `synthetic/` - structured and matched-FP benchmarks and their diagnostics (Table 1).
- `architectures/<arch>/seed<k>/` - per-run validation outputs: training histories and logs, diagnostic
  features and probe results (Table 2), router selection (`router_v3/`) and deployed-router evaluation
  (`router_v3_eval/`), expert training history and safety-gate decision (`mdcr_v3/`), forced-routing upper
  bounds (`upper_bounds/`), and `FINAL_ROUND_DECISION.json`.
- `locked_test/` - official-test evaluation (baseline, control, safety-selected MDCR).
- `ablations/` - seed-42 expert ablations.

Not included: checkpoints, images/masks, per-case route-policy tables (`route_policy_*_aug.csv`) and probe
prediction files, which are regenerated by the pipeline. Absolute paths were replaced by `<DATA_ROOT>`.
In file names, `mdcr_v3` denotes the safety-selected deployment (MDCR (fallback) in the paper).

Run `python scripts/reproduce_paper_tables.py` from the repository root to recompute the paper's numbers.
